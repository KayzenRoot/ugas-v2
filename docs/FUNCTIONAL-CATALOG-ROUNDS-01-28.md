## M28 hard invariants
1. final governed bundles use accepted/authorized artifacts;
2. source release, target and export-profile versions are pinned;
3. missing dependencies or unsupported required capabilities block release;
4. target downgrade is explicit and approval-bound;
5. manifests carry logical IDs, hashes, lineage and governing profile references;
6. M23 remains rights/provenance authority and M24 remains egress/security authority;
7. secrets never enter release manifests;
8. ambiguous external outcomes reconcile before retry;
9. transfer completion is distinct from verified delivery;
10. platform/DCC/game-engine specifics remain adapters and local export remains first-class.
