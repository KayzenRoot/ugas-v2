# Project Overview — UGAS V2

UGAS V2 is a multimodal generative media production operating system that converts creative intent into a reproducible, inspectable, rights-aware, quality-gated Production Graph.

## Problem
Creative AI workflows are fragmented across providers, prompts, files and hardware assumptions. That creates drift, lock-in, non-reproducibility, identity inconsistency, weak provenance, opaque costs and expensive rework.

## Thesis
Intent must be canonical, compiled to interchangeable providers, executed according to actual hardware capability, judged by explicit quality gates, repaired minimally, remembered structurally and traced through provenance.

## Outcomes
Project/Production OS; adaptive compute; model intelligence; multimodal IR; persistent DNA/identity; Image/Video/Animation/3D/Voice/Music/Sound studios; Narrative/Canon; Content Factory; Advertising; Brand/IP; Localization; Quality Court; Repair; Render Cascade; Memory/RAG; Provenance/Rights.

## Primary user
Internal UGAS studio operator/developer. Public SaaS and broad multi-tenancy are not implied V2 scope.

## Posture
Local-first, hardware-agnostic, provider-independent, graph-centric, DNA-first, quality-before-acceptance, provenance-by-design, incremental, cost-aware, observable and human-overridable.

## Current state
Planning/source-pack bootstrap. No product implementation is authorized yet.
