# UI/UX — Dashboard First

## Principle
Dashboard is the primary operator interface and must explain automation.

## Navigation
Home/System Health; Projects; Productions; Production Graph; Assets/DNA; Characters; Image; Video; Animation; 3D; Voice; Music; Sound; Narrative/Canon; Content Factory; Advertising; Brand/IP; Localization; Models; Compute/Hardware/Workers; Quality Court; Repair; Memory; Provenance/Rights; Costs; Automation; Settings/Security.

## Production workspace
1. intent/spec panel;
2. graph/timeline/canvas;
3. inspector/evidence/preview.

## Workflows
Named recipes provide safe defaults. Advanced controls expose model/provider/compute/control parameters without silently mutating canonical intent.

## Explainability
Decision panels show selected option, alternatives, constraints, predicted quality/cost/time, confidence, actual outcome and learning update.

## Quality
Court view shows judges, scores, confidence, evidence, disagreements, defect locations and repair choices.

## Safety/accessibility
Impact confirmation for destructive/external actions; keyboard support; scalable text; non-color-only status; captions/transcripts; readable contrast.
