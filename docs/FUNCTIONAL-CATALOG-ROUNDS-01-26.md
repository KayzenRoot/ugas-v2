## M26 hard invariants
1. telemetry is derived evidence, not canonical production truth;
2. stale/missing telemetry maps to UNKNOWN rather than HEALTHY;
3. dashboard actions use canonical APIs/state machines and M24 capabilities;
4. raw secrets/RESTRICTED data are not general telemetry;
5. high-cardinality IDs belong primarily in events/traces, not metric labels;
6. visible decisions/statuses should link to evidence/canonical records;
7. observability storage, sampling and retention must remain bounded;
8. external observability services remain optional adapters.
