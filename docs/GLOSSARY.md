# Glossary

**Production Graph** — versioned dependency graph representing production intent, execution and derived states.  
**DNA** — canonical identity with invariants, mutable properties, constraints and lineage.  
**IR** — provider-independent intermediate representation of creative intent.  
**Hardware Genome** — normalized declared + empirical compute capability profile.  
**Model Genome** — normalized declared + empirical model capability profile.  
**Multi-Model Director** — planner/router selecting models/providers from fit and constraints.  
**Quality Court** — multi-judge quality evaluation/decision system.  
**Repair Plan** — smallest governed corrective action after quality failure.  
**Render Cascade** — progressive fidelity from cheap candidates to selected final output.  
**Evidence Bundle** — objective proof package for an engineering increment.  
**Context Lock** — base SHA + fingerprints of critical canonical sources.  
**Canonical source** — repository artifact authoritative under Source Hierarchy.
