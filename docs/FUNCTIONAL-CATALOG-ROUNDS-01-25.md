M25 provides content-addressed artifact storage, metadata/object separation, HOT/WARM/COLD placement, safe deduplication, correctness-aware cache reuse, graph-aware lifecycle/GC, storage-pressure control, integrity scrubbing and manifest-driven recovery.

## M25 storage invariants
1. artifact identity is not a filesystem path;
2. canonical/evidence data is not disposable cache;
3. physical deduplication never merges logical rights/security/provenance identities;
4. cache reuse must prove correctness-relevant fingerprint compatibility;
5. graph roots, pins, holds and leases protect data from GC;
6. RESTRICTED placement follows M24;
7. recovery manifests separate required state from safely rebuildable state.
