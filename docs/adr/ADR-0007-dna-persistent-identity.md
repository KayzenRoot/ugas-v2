# ADR-0007 — DNA-based persistent identity

**Status:** ACCEPTED  
**Date:** 2026-09-06

## Context
Assets and characters must survive regeneration, provider changes and cross-modal production without depending on prompt wording.

## Decision
UGAS models persistent identity through versioned DNA, explicit invariants, mutation boundaries, references and lineage. Character identity binds visual, bodily, vocal and behavioral dimensions.

## Consequences
- identity becomes inspectable and testable
- intentional changes require versioning
- quality judges can compare outputs against canonical anchors

## Alternatives considered
- Prompt-only consistency: too fragile
- Reference-file folders without semantic invariants: insufficient
