## M27 hard invariants
1. deterministic workflow/state-machine execution is preferred when reasoning is unnecessary;
2. agent runs bind explicit objective, scope, capabilities, budgets, approvals and stop conditions;
3. schedules/events/webhooks request execution but never grant authority;
4. model/agent output cannot widen capabilities;
5. external/consequential actions use canonical APIs and M24 authorization;
6. retries and duplicate triggers use idempotency/compensation safeguards;
7. agent/workflow state persists outside chat;
8. multi-agent messages never transfer privileges;
9. agents cannot silently modify accepted governance sources;
10. significant automated decisions expose M26-compatible evidence/rationale.
