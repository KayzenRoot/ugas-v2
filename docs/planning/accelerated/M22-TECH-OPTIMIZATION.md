# M22 — Memory & Multimodal RAG: 2026 Technology Optimization
Status: AUTHORIZED CANDIDATE / accelerated planning

## Additions
- **MCR — Multimodal Context Refinery:** hierarchical memory from project/canon/asset/scene/shot/region with semantic compression and provenance.
- **Intent-Aware Temporal Compression:** Tempo-class small-VLM routing is a benchmark candidate for long-video memory, allocating dense representation to query-critical intervals.
- **Evidence-Bound Retrieval:** retrieved memories carry source revision, confidence, rights and validity fingerprints.
- **Cross-Modal Entity Graph:** characters, brands, assets, scenes, audio motifs, campaigns and derivatives share stable identities.
- **Adaptive Context Budget:** context selection accounts for information density, modality cost and task criticality.
- **Memory Conflict Court:** detects contradictory canon/revisions and resolves by source precedence rather than embedding similarity alone.
- **Hot/Warm/Cold Semantic Cache:** coordinate retrieval cache with M25 storage and M21 cost routing.

## Hard rules
RAG cannot override canonical source precedence. Stale or invalidated memories are quarantined, not silently surfaced as truth.
