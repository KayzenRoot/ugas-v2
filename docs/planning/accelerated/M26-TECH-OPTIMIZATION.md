# M26 — Observability & Dashboard: 2026 Technology Optimization
Status: AUTHORIZED CANDIDATE / accelerated planning

## Additions
- **Creative Telemetry Graph:** correlate user intent -> recipe -> node -> model/tool -> hardware -> artifact -> judge -> repair -> acceptance -> delivery.
- **Acceptance Control Room:** dashboard centers on time/cost/quality to accepted deliverable, not generic job counters.
- **Live Quality Heatmaps:** anatomy, identity, motion, topology, temporal, audio, runtime and other domain dimensions by asset/scene.
- **Causal Failure Explorer:** connect failures to dependency deltas, model/tool changes, resource pressure and repair history.
- **Proof Reuse Observatory:** show PROVEN/CARRY_FORWARD/INVALIDATED/UNKNOWN plus saved GPU/test time.
- **Agent Trace Projection:** compact semantic traces, policy decisions and tool actions without dumping sensitive raw context.
- **Predictive Acceptance ETA:** consume M01 AETA/QACP with confidence ranges.
- **Operator Digital Twin:** real-time topology of workers, GPU/VRAM, models resident, queues, branches and active experiments.

## Hard rules
Real-time dashboard is an operational control plane but cannot mutate canonical state outside governed commands. Telemetry must be privacy/redaction aware.
