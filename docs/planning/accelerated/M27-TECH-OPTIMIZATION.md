# M27 — Automation & Agents: 2026 Technology Optimization
Status: AUTHORIZED CANDIDATE / accelerated planning

## Additions
- **Micro-Agent Runtime:** small bounded specialists receive compiled Context Packs instead of broad repository/product context.
- **Agent Capability Tokens:** permissions scoped by WO/session, tool, paths, data class, budget and expiry.
- **Deterministic Tool Plane:** agents orchestrate stable CLI/API/MCP primitives; free-form GUI interaction is fallback, not foundation.
- **Mixture-of-Agents Recipes:** planner may fan out specialized workers, verifier/judge and synthesizer under bounded workflow contracts.
- **Agent State Projections:** replayable compact state instead of uncontrolled transcript growth.
- **Autonomous Recovery Ladder:** retry transient failures, switch qualified implementation, repair bounded delta, then stop/escalate.
- **Agent Economy Controller:** allocate reasoning/model/tool budgets by task uncertainty and impact.
- **HEDS Agent Auditor:** independent delta/evidence review remains separated from executor role.

## Hard rules
Agents do not redesign architecture or expand scope silently. Tool calls, permissions, costs, state transitions and evidence are auditable.
