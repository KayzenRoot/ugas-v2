# S06-S10 Bounded Context Pack

Status: PREPARED CANDIDATE. Never execute all shards as one Codex context.

## S06 Platform Trust
Security precedes access, storage precedes reusable provenance, provenance precedes memory reuse. M24 owns authorization/trust/secret boundaries. M25 owns immutable artifact/storage/cache semantics. M23 owns rights/provenance/credentials. M22 owns scoped memory and context compilation. Golden proof: an authorized artifact is fingerprinted, rights/lineage recorded, indexed only in the correct project scope, then retrieved into a provenance-bearing Context Pack.

## S07 Control, Agents, Delivery
M26 is the realtime operational projection/control surface, not a second source of truth. M27 performs bounded agent steps with minimal tool grants. M28 compiles validated artifacts for delivery and records receipts. Golden proof: a canonical event appears in dashboard state, an authorized action is dispatched through a bounded agent/control path, and a provenance-bearing package reaches a target adapter.

## S08 R&D + DCC
M29 is the only promotion gate for genuinely new technologies. Discovery alone never creates a production dependency. Qualification covers benchmark, license, security and hardware envelope. M30 converts canonical DCC intent into checkpointed, transactional, headless-capable execution. Golden proof: a candidate technology is qualified or rejected from evidence; a qualified adapter participates in a DCC transaction that can validate, commit or roll back without manual GUI dependency.

## S09 Creative + World + Virtual Studio
M31 owns creative executive intent and bounded direction. M32 owns explicit executable world state and causal/versioned snapshots. M33 owns virtual production execution from an approved direction + world snapshot through stage/camera/light/performance/takes/edit/reshoot. Golden proof: creative locks survive simulation and production; a take is bound to a world snapshot; continuity is checked; a local defect triggers selective reshoot rather than whole-production restart.

## S10 Global Optimization + Appearance + Adaptive Experience
M34 chooses the highest-value path to an accepted artifact while hard gates remain constraints. M36 reconstructs/represents/distills appearance and measures neural-to-analytic/runtime loss. M35 creates governed adaptive derivatives from accepted masters and learns from bounded experiments without modifying the master. Golden proof: optimization reuses valid evidence, appearance reaches an accepted runtime representation, then adaptation creates an accessible/privacy-safe derivative whose experiment changes only an approved variable.

## New-technology rule
For every provider/model/research technique that appeared after the current qualified baseline, register it in M29 as a TechnologyCandidate. Record source/date, claimed capability, license, security surface, expected VRAM/RAM/latency/cost and benchmark protocol. Only PROMOTED candidates may become default production routes. This keeps UGAS aggressive about 2026 technology without turning novelty into architecture debt.
